## 5. How to cite on a slide

- For PQC: *"NIST FIPS 203 / FIPS 204, August 2024."*
- For watermarking: *"DCT quantization-index-modulation; blind extraction."*
- For the ledger: *"Replicated Merkle-checkpointed signed ledger; not a consensus blockchain."*
- Never cite an unverified blog for a security claim.
