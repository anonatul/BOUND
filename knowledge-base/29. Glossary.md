## Cryptography

| Term | Meaning |
|---|---|
| **PQC** | Post-Quantum Cryptography — algorithms believed secure against quantum computers |
| **ML-KEM** | Module-Lattice Key-Encapsulation Mechanism, NIST FIPS 203 (formerly Kyber) |
| **ML-DSA** | Module-Lattice Digital Signature Algorithm, NIST FIPS 204 (formerly Dilithium) |
| **KEM** | Key-Encapsulation Mechanism: produces a shared secret + ciphertext from a public key |
| **Encapsulation / Decapsulation** | Create / recover the shared secret |
| **AES-256-GCM** | Authenticated symmetric encryption used for the document and key wrapping |
| **AEAD** | Authenticated Encryption with Associated Data |
| **scrypt** | Memory-hard password-based KDF used to protect private keys at rest |
| **Canonical serialization** | Deterministic JSON (`sort_keys`, compact) so signatures are stable |
| **Non-repudiation** | Inability to deny having signed; weakened here because the server signs |
| **Hybrid encryption** | KEM wraps a random AES key; AES encrypts the data |

## Watermarking

| Term | Meaning |
|---|---|
| **Watermark ID** | `WM-` + 26 base32 chars = 128-bit opaque fingerprint |
| **Session** | `SES-` + 6 hex chars, fresh per decryption |
| **Nonce** | 16 random bytes (128 bits) per decryption |
| **DCT** | Discrete Cosine Transform, used to move pixels into frequency coefficients |
| **QIM** | Quantization Index Modulation — encode a bit in coefficient parity |
| **Payload** | 29 ID bytes + 4-byte CRC32 |
| **Repetition code** | Each bit written R=5 times; majority-voted on extraction |
| **Blind extraction** | Recover the watermark without the original file |
| **Zero-width marker** | Bits hidden as U+200B / U+200C framed by U+2060 |
| **Container fallback** | ZIP archive comment carrying the ID for otherwise unsupported files |
| **PSNR** | Peak Signal-to-Noise Ratio; invisibility measure (> 30 dB asserted) |

## Ledger

| Term | Meaning |
|---|---|
| **Entry** | One ledger record: event + recipient signature + hashes + node signature |
| **Checkpoint** | Signed Merkle root over a node's entries at an index |
| **Merkle root** | Hash of a binary tree over entry hashes; detects truncation/rewrite |
| **Genesis hash** | `"0"*64`, the previous hash of entry 0 |
| **Quorum** | Minimum accepting nodes: 3/4 local, strict majority in LAN |
| **Divergent node** | A node whose chain is invalid or disagrees with the majority |
| **Node agent** | The standalone per-device ledger service (`node_agent.py`) |
| **Member** | A device registered with the coordinator in LAN mode |
| **Repair** | Re-sync a bad node by re-signing the canonical chain locally |
| **Tamper-evident** | Unauthorized changes are detectable (NOT immutable) |
