# 19. Testing & Evidence

> **Status:** Living document
> **Version:** 1.0
> **Last Updated:** 2026-09-27

---

## 1. How to run

```bash
uv run pytest backend/tests -q
```

**Measured on 2026-09-27:** `110 passed, 2 warnings in 11.22s`.

The two warnings are dependency deprecations (Starlette/httpx), not failures.

## 5. What is NOT tested

- Camera / print-scan robustness (deliberately not claimed).
- Adversarial watermark removal.
- Fuzzing / property-based testing.
- Load / concurrency / multi-user stress.
- A formal security audit.
- Windows launcher beyond a syntax-tolerant review (`start_node.ps1`).

Stating this openly is stronger than pretending coverage is complete.
