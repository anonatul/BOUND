## 1. Prerequisites

| Tool | Version | Why |
|---|---|---|
| Python | 3.11+ | backend |
| `uv` | recent | Python deps + runner |
| Node.js | 20+ | frontend build |
| Docker (optional) | recent | container demo |

Python deps (from `pyproject.toml`): FastAPI, uvicorn[standard], `pqcrypto`,
`cryptography`, `pymupdf`, `pillow`, `numpy`, `scipy`, `reportlab`, `python-multipart`,
`pydantic`. Dev: `pytest`, `httpx`.

## 2. Backend (serves the built frontend too)

```bash
uv sync --python 3.11
uv run uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
# App:  http://localhost:8000
# Docs: http://localhost:8000/docs
```

On startup the app creates the demo recipients if missing. `frontend/dist` is served at `/`
when it exists.

---

## 3. Frontend development

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173, proxies /api → :8000
npm run build    # production build → frontend/dist
```

Build once before a single-process demo so `http://localhost:8000` serves the SPA.

---

## 4. Docker

```bash
docker compose up --build
# http://localhost:8000
```

The Dockerfile:
1. builds the frontend in `node:20-slim`,
2. installs the backend on `python:3.11-slim` with `uv`,
3. copies the built `dist`, creates ledger/storage/keys dirs,
4. runs `uvicorn backend.app.main:app --host 0.0.0.0 --port 8000`.

Compose mounts `./ledger`, `./storage`, `./backend/keys` as volumes and restarts unless
stopped. The 4 ledger nodes are directories in local mode (the compose comments say so).

## 7. Common operations

| Task | Command |
|---|---|
| Run tests | `uv run pytest backend/tests -q` |
| Run one test | `uv run pytest backend/tests/test_crypto.py::test_complete_end_to_end_attribution -q` |
| Wipe local ledger (keeps node keys) | `clear_ledger()` from `backend.app.ledger.ledger` |
| Reset runtime data | delete `storage/*`, `ledger/node*/ledger.jsonl`, `ledger/node*/checkpoints.jsonl`, `backend/data/` |
| Rebuild frontend | `cd frontend && npm run build` |
| LAN coordinator | `BOUND_LEDGER_MODE=lan BOUND_ENROLL_TOKEN=… uv run uvicorn backend.app.main:app --host 0.0.0.0 --port 8000` |
| LAN node | `BOUND_NODE_ID=laptopB BOUND_NODE_PORT=9101 BOUND_COORDINATOR_URL=http://<coord-ip>:8000 ./scripts/start_node.sh` |

## 8. Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `BOUND_LEDGER_MODE` | `local` | `local` (4 dirs) or `lan` (remote nodes) |
| `BOUND_LEDGER_ROOT` | `<repo>/ledger` | per-device node data dir |
| `BOUND_NODE_ID` | `node1` | LAN node identity |
| `BOUND_NODE_PORT` | `9101` | LAN node listen port |
| `BOUND_COORDINATOR_URL` | — | coordinator to auto-join |
| `BOUND_ENROLL_TOKEN` | — | shared secret gating LAN joins |
| `BOUND_MEMBERS_FILE` | `<repo>/ledger-members.json` | membership registry |
| `BOUND_LAN_TIMEOUT` | `5` | HTTP timeout to nodes (s) |
| `BOUND_HEARTBEAT_SECONDS` | `30` | node re-announce interval |
| `BOUND_ANNOUNCE_TIMEOUT` | `8` | join call timeout (s) |

## 9. Quick troubleshooting

| Symptom | Fix |
|---|---|
| `ModuleNotFoundError: pqcrypto` | `uv sync --python 3.11` (do not substitute RSA) |
| Site loads but API 404s | rebuild frontend or run the dev server with the proxy |
| "Private key is locked" | use Unlock, or re-login |
| Ledger integrity FAILED | `/api/ledger/repair`, or wipe runtime ledger for a clean demo |
| Port 8000 busy | change `--port` and the Vite proxy target |
| Docker build slow | first `uv sync` downloads PQC wheels; subsequent builds are cached |
