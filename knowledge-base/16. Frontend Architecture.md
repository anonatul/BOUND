# 16. Frontend Architecture

> **Status:** Living document
> **Version:** 1.0
> **Last Updated:** 2026-09-27
> **Code:** `frontend/src/` (React 18 + Vite 5, no UI library)

---

## 1. Stack

| Piece | Choice |
|---|---|
| Framework | React 18 |
| Build | Vite 5 (`@vitejs/plugin-react`) |
| Routing | none — a single `page` state in `App.jsx` |
| State | local `useState`/`useCallback` + prop drilling |
| Styling | one hand-written `index.css` design system |
| HTTP | `services/api.js` (fetch wrapper, bearer token in `localStorage`) |
| Icons | inline SVG in `AppNav` / components |

No Redux, no React Router, no component library, no Tailwind.

## 4. API layer behaviour

`services/api.js`:
- Token key `bound_token` in `localStorage` (falls back to memory if storage is blocked).
- Attaches `Authorization: Bearer <token>` when present.
- FormData for multipart uploads (`encrypt`, `verify`).
- On any `401`: clears the token, calls the registered `unauthorizedHandler` (App drops to
  Login), and throws `ApiError`.
- Network failure produces a friendly "backend not running" message.
- Wraps every endpoint; `api.tests.*` wraps the demo endpoints.

## 5. UX behaviours worth demoing

- Passphrase show/hide while typing; live username availability on register.
- Type badges and correct download extension (native vs `.zip`).
- Unlock state badge with expiry; auto-prompt to unlock when decrypting locked keys.
- Audit page plain-language explanations and "Re-sync from quorum".
- Global search that can jump to a document, a person, or a ledger entry.
- Toasts for successes and errors.

## 6. Build & serve

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173, proxies /api → :8000
npm run build    # writes frontend/dist
```

At runtime FastAPI mounts `frontend/dist` at `/` when it exists
(`main.py` end-of-file), so a single `uvicorn` process serves both the API and the SPA.
During development, Vite proxies `/api` to port 8000 (`vite.config.js`).

## 7. Frontend security notes

| Note | Detail |
|---|---|
| Token storage | `localStorage` (XSS-exposed; prototype choice) |
| CORS | backend allows `*` (prototype; tighten for production) |
| No client-side crypto | all signing is server-side; the browser never holds keys |
| Downloads | short-lived HMAC token in the URL query |

These are prototype trade-offs, stated honestly; none are claimed as production-hardened.
