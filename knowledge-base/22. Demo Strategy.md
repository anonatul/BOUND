# 22. Demo Strategy

> **Status:** Living document
> **Version:** 1.0
> **Last Updated:** 2026-09-27

---

## 1. The story (say this first)

> **"You can't stop a trusted insider from leaking a document. But you can make every
> decryption leave a unique invisible fingerprint and a post-quantum-signed record — so when
> a copy leaks, you can prove which recipient and which session produced it. Fully offline."**

Then the one-line why-it-matters:

> **"Existing logs are mutable; static watermarks are identical for everyone; DRM dies to a
> phone camera. BOUND doesn't prevent the leak — it proves the source."**

---

## 2. The 5-minute script

| Time | Beat | Action |
|---|---|---|
| 0:00–0:30 | Problem | A leaked doc cannot be tied to a person; logs are editable |
| 0:30–1:00 | Idea | Encrypt once → per-session invisible fingerprint → signed → offline ledger |
| 1:00–2:00 | Share + decrypt | ALICE shares to BOB; BOB (and ALICE) decrypt; show two different `WM-…` IDs and two sessions; point out both files open normally and PDF text is still selectable |
| 2:00–3:00 | Leak → attribute | Upload Alice's downloaded copy to Verify → **VERIFIED**, recipient ALICE, session, signature VALID, quorum VALID |
| 3:00–4:00 | Tamper → fail | Run `signature tampering` and `admin tamper (all 4 nodes)`; show both fail |
| 4:00–4:30 | Offline / LAN | Show Audit: per-node signatures + Merkle checkpoints; mention each node key lives on a separate device in LAN mode |
| 4:30–5:00 | Honesty close | "We don't claim camera-proof watermarks or human-action proof; here is exactly what we guarantee." |

## 3. The exact demo click-path

1. Login as `ALICE` / `demo12345`.
2. Files → upload any file → select `ALICE`, `BOB` → Share.
3. Sign out → login `BOB` / `demo12345` → Shared with me → Decrypt → note `WM-…` and
   `SES-…` → Download.
4. Sign out → login `ALICE` → Shared with me → Decrypt → note a **different** `WM-…`.
5. Download Alice's file.
6. Verify → drag Alice's downloaded file → show verdict card:
   - Status **VERIFIED**
   - Recipient **ALICE**, session `SES-XXXXXX`
   - Signature **VALID**, node quorum **4/4**
   - Format `pdf`
7. Security demos → run:
   - **End-to-end** (all checks true)
   - **Signature tampering** (signature INVALID)
   - **Admin tampering (all 4 nodes)** (rejected; node signatures invalid)
8. Audit → show entries, per-node valid nodes, Merkle root, checkpoints. (Local mode.)

---

## 4. If you have the LAN setup (strongest version)

1. Coordinator + 3 witness laptops on an isolated router.
2. Decrypt once → Audit shows all witness node signatures.
3. Tamper one witness's `ledger.jsonl` → Audit flags it; Verify still attributes.
4. "Re-sync from quorum" → repaired by local re-signing.
5. Show that only the **public** key is exposed by `/node/info`.

This is the version that makes "no single administrator" undeniable.

---

## 5. Backup plan (no network / no time)

- Everything runs locally (`BOUND_LEDGER_MODE=local`), no internet.
- If the frontend fails: use `http://localhost:8000/docs` and call
  `POST /api/test/end-to-end` directly; read the JSON `checks`.
- If the ledger looks dirty after demos: `POST /api/ledger/repair`, or wipe runtime ledger.
- Keep a pre-decrypted sample in `storage/watermarked/` for `/api/test/attribution`.

## 6. Lines that land

- "The fingerprint is **opaque** — the artifact never contains a name; only the ledger maps it."
- "Each node signs every entry with its **own** ML-DSA key — an admin with file access but not
  the keys cannot forge a consistent rewrite."
- "This is a **chain of evidence**, not DRM."
- "We tested it: 110 automated tests, including a real 4-process LAN quorum."

## 7. Lines never to say

- ❌ "AI-powered" — there is no ML.
- ❌ "The watermark cannot be removed."
- ❌ "It survives screenshots / print-scan."
- ❌ "It's a blockchain / immutable."
- ❌ "It proves the person did it."

## 8. Closing sentence

> **"BOUND proves which authorized session produced a leaked copy, offline, with
> post-quantum signatures and a tamper-evident ledger — and we're honest about exactly
> where that proof ends."**
